# Simple E-commerce Store - CodeAlpha Internship

This is a fully functional **MERN Stack (MongoDB, Express.js, React, Node.js)** E-commerce web application developed as part of my Full Stack Development Internship at **CodeAlpha**.

## Features
- **User Authentication:** Secure register and login system using bcryptjs and JWT.
- **Product Showcase:** Home page displaying all available products with details.
- **Product Details:** Dedicated page for individual product information.
- **Shopping Cart:** Add, remove, and update products in the cart.
- **Order Processing:** Place orders securely (simulated checkout).
- **Responsive UI:** Clean design that works on both desktop and mobile devices.

## Tech Stack
- **Frontend:** React, Vite, Axios, React Router DOM, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose Object Modeling)
- **Security:** JSON Web Tokens (JWT), BcryptJS
